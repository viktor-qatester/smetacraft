# Frontend SmetaCraft после Phase 5

`index.html` содержит разметку и стили. JavaScript загружается обычными `<script src>` через HTTP(S), без сборщика. Порядок тегов в конце `index.html` является частью контракта и проверяется `tests/runtime.cjs`.

| Слой | Файлы | Предоставляет / получает |
| --- | --- | --- |
| Расчётное ядро | `js/core/*.js` | Чистые `createCalculator`; получают константы и помощники, возвращают строки `name/netLabel/k/orderLabel/cost`. |
| UI-контроллеры оснований | `js/ui/slab.js`, `js/ui/strip.js` | Чтение, проверка, показ ведомости и события форм; зависимости передаются через `createController`. |
| Конфигурация и состояние | `js/app/config.js`, `state.js` | Константы, NormalizedProjectModel, единственные переменные состояния и DOM-ссылки. |
| Общие средства | `js/app/utils.js`, `bill.js`, `price.js`, `piles.js`, `foundations.js` | Числовые и форматирующие функции, безопасный вывод, прайс-лист, DOM-адаптер свай, подключение расчётов оснований. |
| Предметные потоки | `js/app/walls.js`, `plaster.js`, `roof.js`, `floor.js` | Чтение и проверка форм, показ результата, обработчики. Формулы закупки остаются в `js/core`. |
| Связи и сводная | `js/app/links.js`, `summary.js`, `render.js` | Автоподстановка геометрии, строки и итог сводной, единая маршрутизация `render()`. |
| Проект и запуск | `js/app/intake.js`, `regression.js`, `project.js`, `reset.js`, `file-import.js`, `backend-check.js`, `boot.js` | Анкета, встроенный контроль, JSON v1, `localStorage`, новый проект, импорт файла, явная проверка серверного приёма и однократная подписка на события. |

Файлы `js/app` используют общую область имён классических скриптов. Поэтому загрузка идёт строго в указанном в `index.html` порядке: ядро → контроллеры → конфигурация и состояние → общие функции → потоки → сводная → проект → `boot.js`. `boot.js` запускается последним; до него файлы в основном объявляют функции и не меняют проект. Состояние не дублируется между потоками. При добавлении нового файла обновить порядок и список в `tests/runtime.cjs`.

`tests/runtime.cjs` исполняет настоящие файлы в Node VM в том же порядке. Он подставляет DOM-ссылки и пропускает только `state.js` и `boot.js`, где нужен полный браузерный DOM; поведение событий дополнительно проверяется через HTTP в браузере. Сохранённый `tests/golden.json` сравнивает строки и суммы без автоматического обновления эталона.

Phase 5 сохраняет JSON v1, ключ `smetacraft_project`, внешний вид, печать и формат ведомости. В будущем можно ввести ES modules с явными `import`/`export`; такая миграция меняет контракт загрузки и требует отдельного плана и браузерной проверки.

Phase 6 добавляет локальный `server/server.cjs` на Node.js: статическая раздача и `POST /api/project-check` на том же origin. Запрос запускается только кнопкой в разделе проекта; сервер возвращает размер и SHA-256 принятых байтов, не сохраняя проект. Расчёты и `localStorage` остаются браузерными.
