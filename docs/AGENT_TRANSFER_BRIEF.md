## 2. Характеристика приложения

### Назначение

Smetacraft — автономный веб-конструктор ведомостей материалов к закупке для строительства. Ввод габаритов → спецификация с запасами, раскроем и ориентировочной стоимостью в Br.

### Аудитория

- **Прорабы/мастера** — все модули, технические параметры.
- **Заказчики** — вкладка «Мой дом»: простые вопросы, сводная смета без JSON.

### Стек

- Один файл `index.html`: Vanilla HTML/CSS/JS, без Node.js и сборщиков.
- UI: параметры слева, ведомость справа (sticky с 900 px).
- Расчёт: детерминированный JS, без LLM и внешних API.
- Данные: localStorage, экспорт/импорт JSON, печать/PDF.
- Регрессионные тесты при загрузке (бейдж справа).

### Модули (все реализованы)

- **Плитный фундамент** — бетон +5%, арматура (40d, хлысты), опалубка, подушка, гидроизоляция +15%
- **Ленточный фундамент** — бетон, арматура, хомуты, опалубка, подушка, гидроизоляция
- **Стены** — газобетон/кирпич, клей, армирование, проёмы, перемычки
- **Перекрытия** — дерево или ЖБ
- **Штукатурка** — гипс/ЦПС, грунтовка, маяки, сетка
- **Кровля** — стропила, обрешётка, утепление, покрытие
- **Сводная смета** — агрегация узлов, общий итог, печать

### Границы продукта

Предварительная ведомость закупки, не проектная документация. В UI — блок «Границы расчёта». Цены — ориентир.

### Документация в репо

- `AGENTS.md` — правила разработки
- `PRODUCT_SPEC.md` — ТЗ и модули
- `README.md` — запуск и проверки
- `docs/HANDOFF.md`, `docs/ROADMAP.md`, `docs/NEXT_SESSION_PROMPT.md`

## 3. Что изменили при переносе (4 коммита)

### Коммит 1 — ряды сетки в плите (`db1da69`)

Файлы: `index.html`, `PRODUCT_SPEC.md`

- Селектор `#bar-mesh-layers`: 1 / 2 (default) / 3 ряда
- Читается в `readForm`, валидируется, умножает стержни в `calculateSlab`
- Регрессия: 70 и 140 хлыстов

| Рядов | Хлыстов | Br |
| :---: | :---: | ---: |
| 1 | 70 | 9 741,19 |
| 2 | 140 | 12 099,19 |
| 3 | 210 | 14 457,18 |

(плита 10×8 м, шаг 200 мм, Ø12)

### Коммит 2 — превью и дисклеймер (`a4652e4`)

Файлы: `index.html`, `README.md`, `assets/og-cover.html`, `og-cover.png`

- Open Graph / Twitter / description
- Favicon как data: URI
- Обложка 1200×630 из HTML (не SVG — кириллица в headless ломается)
- Шапка: «детерминированный расчёт» + «Границы расчёта»

### Коммит 3 — документация (`b0a73b0`)

`docs/HANDOFF.md`, `docs/ROADMAP.md`

### Коммит 4 — промт (`d993b51`)

`docs/NEXT_SESSION_PROMPT.md`

**Не менялись:** лента, стены, кровля, штукатурка, перекрытия, сводная (кроме влияния рядов сетки в плите).

## 5. Задачи для доработки

1. **Разделить ядро и тесты** — модули расчёта, тест-раннер в терминале
2. **Мгновенное погружение** — предзаполненный объект, шаги, мобильный sticky-итог
3. **Подготовка к продажам** — лицензия, домен, лендинг / + app `/app`

**Не начинать без владельца:** сервер Fornex, монетизация (расчёт vs сервис).

Подробности: `docs/NEXT_SESSION_PROMPT.md`, `docs/ROADMAP.md`.
