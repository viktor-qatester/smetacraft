# SmetaCraft Annotation Dataset v0.1

Дата: 2026-09-22

## Что это

Первый эталонный набор ручной разметки для будущего импорта строительных PDF в SmetaCraft.

Размечено 5 документов:

1. Русский свайно-ростверково-плитный фундамент.
2. Русская фундаментная плита с ленточными рёбрами.
3. Англоязычный комплект гражданских и конструктивных чертежей.
4. Англоязычный проект усиления металлическими профилями.
5. Старый скан расширяемого фермерского дома без текстового слоя.

Основной фокус v0.1: фундамент, плита, ростверк, сваи, бетон и арматура. Стальной проект добавлен для проверки расширяемости модели. Скан NDSU добавлен как отрицательный/OCR-кейс.

## Файлы

- `field_catalog.csv` - словарь допустимых полей.
- `annotations.json` - эталонные значения с указанием страницы и доказательства.
- `validation_report.md` - результат автоматической проверки структуры.
- `validate_annotations.mjs` - воспроизводимая проверка.
- `dataset_manifest.csv` - источники, контрольные суммы и метаданные 12 PDF корпуса.

Исходные PDF не хранятся в Git: часть авторов разрешает публичный просмотр, но лицензия на повторное распространение подтверждена не для всех документов. Полный рабочий корпус хранится отдельно. Разметка ссылается на имена файлов из манифеста.

## Статусы

- `confirmed` - значение явно указано на листе и проверено визуально.
- `needs_review` - значение похоже на правильное, но источник неоднозначен или OCR ненадёжен.
- `not_found` - значение не найдено; запрещено превращать его в `0`.

## Важное правило интеграции

Разметка не является результатом расчёта SmetaCraft. Это только извлечённые факты для черновика `NormalizedProjectModel`.

Правильная цепочка:

`PDF -> extracted facts -> пользователь подтверждает -> Calculation Core`

Нельзя передавать `needs_review` или `not_found` в расчёт как подтверждённые исходные данные.

## Ограничения v0.1

- Пять документов недостаточны для обучения отдельной ML-модели.
- Англоязычные нормы и обозначения не должны автоматически переноситься на белорусские/российские расчёты.
- Разметка не подтверждает пригодность проекта для строительства.
- Адреса и персональные данные намеренно не размечались.

## Проверка

Проверка структуры, типов, страниц по манифесту и доказательств:

```bash
node validate_annotations.mjs
```

Если полный PDF-корпус доступен локально, дополнительно проверяются наличие файлов, реальное число страниц и SHA-256:

```bash
SMETACRAFT_CORPUS_DIR=/path/to/smetacraft_pdf_dataset node validate_annotations.mjs
```
