# Документ → Markdown перед анализом

Применяй, когда нужно **прочитать содержимое** PDF, Word, Excel, PowerPoint, ODT/ODS/ODP, RTF, EPUB или CSV. Сначала получи Markdown, потом читай только нужные фрагменты.

Не применяй, если файл уже Markdown/текст, если это `smetacraft-project` JSON, или если задача — импорт в калькулятор. HTML AnyDoc не поддерживает.

## Зачем

Бинарный PDF/DOCX агент читает плохо и дорого. Markdown короче и пригоден для поиска. Это экономия контекста, не распознавание сметы.

## Команда

CLI: `@firecrawl/anydoc` (локальный Rust, без ключа). Сначала `anydoc`, если нет — `npx -y @firecrawl/anydoc`.

```text
anydoc <файл> -o <файл.md>
npx -y @firecrawl/anydoc <файл> -o <файл.md>
```

Большой файл всегда пиши в `-o` и читай куски. Не лей весь Markdown в чат, если достаточно раздела.

Коды: `0` успех, `1` не конвертировался, `2` ошибка вызова, `3` PDF без текста / нужен OCR.

## Форматы

Есть: `.doc`, `.docx`, `.pdf` (текстовый), таблицы, презентации, OpenDocument, RTF, EPUB, CSV.

Нет:

- **HTML / HTM** — не вызывать AnyDoc. Для разбора HTML не использовать HTML-парсер калькулятора; в смету текст не подставлять через `innerHTML`.
- Сканы и PDF-картинки — локально падают с кодом `3`. `--ocr hosted` шлёт файл на Firecrawl Parse; **не включать**, пока владелец явно не разрешил отправку документа во внешний сервис.

Формат берётся из содержимого, не из расширения. `--format` нужен для CSV со stdin.

## Граница SmetaCraft

Конвертация **не импорт проекта**. Действующий импорт — JSON v1 в `js/app/file-import.js` / `project.js`. Phase 8 (PDF/DOCX → смета) не открыта: без утверждённого образца и mapping-contract не выбирать формат и не писать универсальный импортёр.

Запрещено:

- подставлять Markdown в `applyProject`, `localStorage` или поля формы как будто это `smetacraft-project`;
- менять формулы, `tests/golden.json` или расчёт по тексту документа;
- класть загруженные оригиналы и `.md` в статический корень / коммитить чужие документы.

После конвертации можно только анализировать текст и **предложить** параметры владельцу. В смету — только после явного подтверждения и отдельного согласованного импорта.

## Проверка CLI

```text
anydoc --version
anydoc <локальный.docx|pdf|csv> -o /tmp/out.md
```

Ожидание: код `0` и читаемый Markdown. Для `.html` ожидается отказ `unsupported input`.
