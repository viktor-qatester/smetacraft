# Проверка сметных формул

Прочитай `AGENTS.md`, `PRODUCT_SPEC.md`, затронутые `calculate*`/`validate*` функции `index.html`, соответствующие сценарии в `tests/scenarios.cjs` и `docs/regression-baseline.md`. Проверяй один согласованный модуль за раз; готовые соседние модули не редактируй.

Для каждого изменённого материала зафиксируй цепочку: вход и единицы → геометрия/чистый расход → коэффициент с основанием → округление к закупке → цена → `name`, `netLabel`, `k`, `orderLabel`, `cost` → сумма. Отдельно проверь граничные условия, нулевые и недопустимые значения и связь с соседним разделом сводной. Сделай независимый ручной контрольный расчёт с явными цифрами и сравни его с итоговой ведомостью; одинаковый код в тесте не является независимым доказательством.

Различай действующий контракт приложения и внешнюю строительную норму. Для утверждения о действующей норме или безопасности конструкции ищи актуальный первичный источник; без него отмечай допущение, а не выдумывай коэффициент. Уже заданные контрактом значения (бетон +5%, 40d, 11,7 м, гидроизоляция +15%, подушка ×1,10) не меняй без согласованной причины. Не оставляй TODO, приблизительный или случайный расчёт и не вызывай LLM для математики.

Выход: таблица проверенных формул и единиц, ручной пример, точные расхождения или подтверждение совпадения, влияние на строки и сумму, оставшиеся допущения. Если задача включает исправление, изменяй лишь разрешённый модуль и передай новые сценарии скиллу `smetacraft-regression-tests`.
